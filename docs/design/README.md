# Knowvia design brief: landing page and onboarding

This folder holds the design brief for the Knowvia landing page and onboarding. The brief will be handed to
Claude Design to build. It is documentation only and changes no product code.

Start with [00-requirements-and-framework.md](00-requirements-and-framework.md). It holds the decisions,
non-negotiables, success metrics and checkpoint procedure that every other file follows.
